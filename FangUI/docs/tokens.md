# FangUI 令牌

> 由 `npm run build:docs` 从 `src/theme/tokens.ts` 生成，别手改。

令牌就是 `.cui` 里能直接写在属性值里的词：`background canvas`、`color accent`。
编译后是 `var(--canvas)` 这类 CSS 变量；换主题只换变量值，界面一个字都不用改。

## 尺度

| 类 | 取值 |
| --- | --- |
| 间距 | 1=4px · 2=8px · 3=12px · 4=16px · 5=24px · 6=36px |
| 圆角 | xs=2px · s=4px · m=8px · l=12px · xl=16px · full=999px |
| 字号 | xs=12px · sm=13px · md=14px · lg=20px · xl=28px |
| 控件高 | s=24px · m=32px · l=40px |
| 图标 | s=16px · m=20px · l=24px |
| 动效 | fast=120ms · base=160ms · slow=240ms |
| 层级 | base=0 · sticky=10 · dropdown=15 · overlay=30 · modal=40 · toast=50 · tooltip=60 |

尺度不可换主题，只跟"密度"有关。想要更紧凑的界面，覆盖 `--control-m` 之类的变量即可。

## 强调色

挂 `data-accent` 到根元素或 window 就能整站换品牌色；`.cui` 里用 `act accent blue`。

| 名字 | 亮色 | 暗色 |
| --- | --- | --- |
| `green`（默认） | `#0d8a4c` | `#37c185` |
| `blue` | `#0b62c4` | `#5aa9ff` |
| `violet` | `#6b3fc4` | `#a98bfa` |
| `amber` | `#a86200` | `#e8a33c` |
| `rose` | `#b42318` | `#ff8b80` |

## 主题

`data-theme="dark"` 是暗色，`light` 是亮色。写在 `window` 元件上只影响这个窗口，
写在 `<html>` 上影响整页。旧写法 `.night` 类仍然认。

亮色底色：`#f7f7f7` / 暗色：`#17191b`。
